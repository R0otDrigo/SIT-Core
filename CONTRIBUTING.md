# Guía de Contribución para SIT-Core

## Convención de Ramas
- `feat/nombre`: Para nuevas características.
- `fix/nombre`: Para corregir errores.
- `docs/nombre`: Para cambios en documentación.
- `chore/nombre`: Para tareas de mantenimiento.

## Convención de Commits
Usar Conventional Commits (ej. `feat: agregar login`).
